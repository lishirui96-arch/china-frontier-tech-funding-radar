# 中国前沿科技融资热点雷达

一个面向中国前沿科技一级市场的融资资料整理、证据核验、企业技术画像、三级产业技术分类与可视化网站项目。

项目将分散的融资报道整理为可追溯的历史记录，在不混淆正式事件和候选事件的前提下，从企业真实产品与核心技术出发建立产业分类，并通过内部审核站和公开展示站持续维护。

## 项目涵盖内容

### 融资资料整理

- 保存原始新闻标题、URL、来源平台和公开日期。
- 保留原始企业名称、融资轮次、金额表述和投资方。
- 区分同一事件的多来源报道、同一企业不同轮次以及历史融资信息。
- 对企业名称截断、轮次冲突、金额残缺和财务顾问误识别进行字段级核验。
- 并购事件与普通融资轮次分开管理。

### 企业技术研究

- 重新阅读来源正文，提取主营业务、核心产品、核心技术和应用场景。
- 不使用融资金额、投资机构或新闻标题替代企业业务画像。
- 支持企业主产业归属、多个技术标签以及多主题产品级关联。
- 证据不足时保留“待补充”，不根据公司名称猜测业务。

### 三级产业技术分类

网站以10个一级产业方向为固定导航：

1. 机器人与具身智能
2. AI计算与半导体
3. AI软件与工业智能
4. 新能源与先进材料
5. 高端装备与先进制造
6. 商业航天与卫星应用
7. 低空经济与无人系统
8. 生物制造与生命科学
9. 脑科学与神经技术
10. 量子科技

当前V3.2包含42个二级领域和51个三级候选主题。分类ID稳定，历史版本和主题调整记录完整保留。新增分类通过独立版本发布，不能直接改写已经冻结的版本。

### 网站

- `8510`：内部审核站，查看来源、企业画像、事件冲突、分类建议和操作历史。
- `8511`：融资热点雷达网站，展示产业分类导航、企业、主题和95个去重后的候选融资事件；97条原始来源记录继续保留用于审计。
- 首页表格展示日期、企业及主营业务、一级/二级赛道、轮次、金额、投资方和原始来源。
- 正式事件、A类候选和B类候选保持独立状态，不把候选包装成已确认事实。

## 数据流程

```text
融资来源
  -> 原始记录留存
  -> 企业实体与字段核验
  -> 重复事件和轮次冲突审计
  -> 企业主营业务/产品/技术画像
  -> 一级产业/二级领域/三级主题建议
  -> 人工审核与版本冻结
  -> 8510内部审核
  -> 8511分类网站
```

## 本地运行

推荐Python 3.11或更高版本。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:PYTHONPATH='.'
python scripts\migrate.py
```

启动内部审核站：

```powershell
streamlit run app\Home.py --server.port 8510
```

启动融资热点雷达网站：

```powershell
python scripts\run_public_site.py --port 8511
```

访问：

- 内部审核站：<http://127.0.0.1:8510>
- 融资网站：<http://127.0.0.1:8511>

## 数据与审核原则

- 不删除历史来源和历史分类版本。
- 不覆盖用户人工审核决定。
- 未披露金额不填写为0。
- 模糊金额不使用区间中值进行精确排名。
- 历史累计融资金额不作为本轮融资金额。
- 同一事件关联多个主题时，全局事件数量只计算一次。
- 企业和主题改名不改变稳定ID。
- 所有分类、合并、拆分和审核操作保留时间、理由及修改前后值。
