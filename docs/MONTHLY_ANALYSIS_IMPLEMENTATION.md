# 首页月度融资分析改版说明

## 页面变化

- 删除首页 90/360 天按钮、统计窗口文案及 `period` 处理逻辑。
- Hero 改为显示已发布事件覆盖月份、数据范围、更新日期和当前 Release。
- 新增联动筛选：赛道、年份、融资轮次、企业名称、投资机构和一键重置。
- 核心区域改为约 2:1 双栏：自然月堆叠柱状图与最活跃投资方 TOP 10。
- 新增融资事件明细表、原文链接和分页。
- 保留六大学科、新兴方向、最新事件，并补充重点企业和投资机构动态区域。

## 统计口径

- 统计对象仅来自最新有效 Release 的不可变 `release_events` 快照。
- 月份按公布日期换算为中国标准时间后的自然月；日期不明确时不强行归月。
- 事件先按 `event_id` 去重；同一企业的不同事件仍分别计数。
- 每个事件只使用明确主赛道。多赛道且没有唯一主赛道时归入“未分类”，避免重复计数。
- 投资机构按标准化 `investor_id` 和唯一事件计数，同一事件内重复角色不重复。
- 没有已验证覆盖声明时不补齐空月份，也不将未采集月份显示为零。
- 金额展示保留原文；累计融资不作为本轮金额，精确金额总计仍只纳入非累计精确值。

## 交互

- 点击月份柱设置 `month` 筛选，再次点击取消；投资方和事件表同步更新。
- 点击图例或赛道快捷项设置/取消 `track` 筛选，三个数据区域同步更新。
- 年份、轮次、企业和机构通过查询表单统一筛选。
- 长时间轴使用横向滚动；当前未引入额外图表框架。
- 排名机构名称和进度条整体链接到机构详情，企业名称链接到企业详情。

真实数据库仍为 0 个事件、0 个 Release。月度图显示“暂无已发布融资数据”，投资方显示“暂无已发布投资机构数据”，明细表不生成任何虚构行。
