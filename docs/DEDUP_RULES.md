# 事件级去重规则 V1

候选召回要求同一标准企业，日期窗口为 7/30/45 天，并结合轮次、金额区间、主要投资机构、文本和引用链。不同企业禁止自动合并；同一企业也不自动等同于同一事件。

候选表保存企业、日期、轮次、金额、投资者、文本、引用链七项分数和强冲突。明确不同轮次是强冲突；补充披露关联同一事件并增加 supporting 文档；追加轮、第二次交割或不同轮次保留独立事件。

初始建议阈值：同企业且总分 ≥0.75、无强冲突为高风险/高相似候选；0.50–0.75 人工判断；其余低风险。V1 不执行自动物理合并。每次决定保存规则版本、理由与操作者；后续决定将旧决定的 `is_current` 置零并通过 `reverses_decision_id` 保留撤销链。原始文档永不删除。
