## 8510 内部审核站

验收通过。导航已显示“V3.0分类与历史迁移”，页面支持：

- 浏览冻结的 10→38→34 分类层级；
- 核对 97 条历史候选记录及其迁移状态；
- 查看原始来源、企业—主题和事件—主题关系；
- 由人工调整主主题、次级主题、暂缓或排除；
- 对冻结分类提交名称变更申请，不直接改写冻结记录；
- 记录审核人、时间、修改前后值和理由。

## 8511 融资雷达站

验收通过。公开展示只读取不可变的 V3.0 Release 快照，已实现：

- 首页展示 10 个一级产业方向、38 个二级技术领域、34 个三级候选主题；
- 分类页支持一级方向→二级领域→三级主题逐层进入；
- 主题页展示层级、企业画像、唯一候选事件、轮次分布、时间线和来源；
- 融资事件、企业库和数据说明页面接入 V3 数据；
- 正式事件、A 类候选、B 类候选分开标识；
- 97 条来源记录与 97 个唯一候选事件分别说明，未将候选包装为正式事件。
