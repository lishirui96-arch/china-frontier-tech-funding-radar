# 金额保真规则 V1

- `5000万元` 等明确数值进入 `amount_exact`，并同步上下界。
- `约/近/超/逾/数/级/左右/以上` 永远不进入 `amount_exact`。
- `近亿元`：`[8000万, 1亿)`，`upper_bound`。
- `超/逾亿元`：`[1亿, +∞)`，`lower_bound`。
- `数千万元`：`[2000万, 9000万]`；`数亿元`：`[2亿, 9亿]`。
- `亿元级/完成亿元融资`：`[1亿, 10亿)`，`order_of_magnitude`。
- `累计融资/总融资`：`cumulative_only`，本轮精确额和区间均为空。
- 未披露或无法可靠解析：`undisclosed`。
- CNY/USD/EUR 保留原币种；V1 不换汇、不跨币种汇总、不取区间中点。

规则定义写入 `amount_rule_versions`，当前为 `1.0.0`；解析器输出规则 ID 与置信度。标题和正文冲突时不自动择高值，保留两条字段证据并进入 `field_review`。
