# V1.1 来源覆盖审计与增量采集计划

计划日期：2026-11-25（Asia/Singapore）  
检索窗口：2026-11-01 至 2026-11-25  
基线：Git `354c994b7a795af4b8bde1530e1a3e45cecb7046`，Schema V3，22条融资事件、6条并购候选、31条原始来源文档。

## 1. 保护基线

1. 只做新增来源、候选和事件；不删除或更新 V1.0 原始事件记录。
2. 使用稳定 ID 与幂等插入；同一 URL、企业、事件和投资机构不会因重复运行而复制。
3. 任何无法确定是否重复、是否目标轮次或是否完成的交易进入待审核线索，不直接形成正式事件。
4. 人工锁定主题、主题动作历史和审计日志只读保护；自动增量只补充未锁定主题或新增观察项。
5. 不创建公开 Release，不把未审核数据送入8511。

## 2. 来源遍历顺序

### A. 投资界/PEDAILY

分别遍历融资大事件、投资事件、天使/早期、并购事件四个入口的公开分页。每页记录栏目、页码、HTTP状态、文章数和日期范围；连续两页最晚文章早于2026-11-01时停止。对窗口内文章读取正文，不按标题提前排除。重点复核金领生物、九天创智、华睿博视、中国电子云、章鱼动力、谱思科技、盖科材料、丝路天图、数字光芯和亿优威光。

### B. SpaceDaily融资数据库

先检查首页、robots.txt、页面脚本、网络请求线索、公开接口/文档/导出、筛选参数、分页和服务条款。只使用无需登录且公开允许的页面或接口；低频访问并记录请求数。其记录只作为发现线索，必须回到原始新闻核验后才能形成事件。

### C. 其他公开来源

以36氪、IT桔子公开页、清科/投资界公开页、投中、财联社、证券时报及可追溯科技媒体进行交叉检索。登录/付费内容仅登记公开元数据，不绕过限制。只保存明确融资事实或可核验线索。

### D. 并购公告

优先检查巨潮、沪深北交易所、上市公司公告和官网；搜索收购、控制权、资产购买、重大资产重组、发行股份购买资产等。区分拟收购、已公告、审批中、已交割、已完成和已终止。

## 3. 来源文档与事件分层

- 原始来源文档：所有可追溯页面，一文档一ID。
- 融资候选：正文存在融资事实但轮次、地域或重复关系尚待判断。
- 正式融资事件：满足地域、日期、轮次和证据门槛后形成唯一事件ID。
- 并购候选：明确收购/兼并/控制权交易但状态或范围待核验。
- 正式并购事件：公告和交易要素足够，仍保留交易状态，不将公告误写为完成。

## 4. 去重与增量判断

综合企业法定名/简称、原始轮次、标准化轮次、金额、投资方、披露日期、正文事实和交割关系。相同事件的多来源全部保留；同轮首次交割、后续交割和追加融资先建关联候选，不能仅凭企业名合并。与 V1.0 无法明确区分的记录进入人工去重审核。

## 5. 来源覆盖指标

按来源与栏目计算：遍历页数、发现文章、窗口内线索、目标轮次候选、并购候选、V1.0重复、新增独立事件、已核实、待核实和不可访问数。另建跨来源事件重合矩阵；所有数字由来源文档和事件关联实际计算。

## 6. 访问与质量约束

- 遵守 robots、服务条款和公开访问边界；不绕过登录、付费墙、验证码或访问控制。
- 请求设置来源级间隔和总预算；错误记录原因，不高频重试。
- 搜索摘要只用于发现，不作为事件证据。
- 金额保留原文和币种；无可靠汇率不填写精确人民币金额。
- S/A/B/C/D按来源性质和可追溯性赋级，媒体知名度不自动产生S级。

## 7. 验收输出

增量融资/并购、合并样本、来源文档库、来源覆盖审计、融资去重审计、并购核验报告、更新七表Excel、来源覆盖统计页面、测试与Git提交。全程不创建公开Release。
