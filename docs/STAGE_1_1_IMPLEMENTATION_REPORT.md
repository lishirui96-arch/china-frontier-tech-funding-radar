## 数据采集模块

URL 规范化仅移除 fragment 和常见跟踪参数，不删除原始 URL。批量导入记录提交、新增、重复、失败和错误；相同 canonical URL 只阻止再次插入同一候选，原始已登记文档不删除。RSS 任务单次最多 5 请求，检查 robots、来源启用状态、最小间隔，记录请求/新增/重复/失败/解析器版本并实施一小时失败退避。

## URL 导入

审核站“URL 导入”支持单条、制表符批量和 UTF-8 CSV。CSV 必填列为 `url,title,source_name`，可选 `published_at,summary`。手工摘要必须是允许保存的原文或摘要；搜索摘要不得填写为原文。导入时自动记录域名、canonical URL、哈希、导入时间和批次结果。

## 来源管理

“来源管理”支持新增、等级、类别、域名、允许范围、最小间隔、启用/停用和审计理由。最近抓取、失败次数和发现运行记录保存在数据库。D 级仅作线索，Release 门槛继续拒绝只有 D 级证据的事件。

## 人工审核流程

文档导入 → 10 类初筛 → 有 span 的字段候选 → 主体确认 → 建立唯一事件/文档/投资方关系 → 事件字段与证据审核 → 去重人工决定/撤销 → 两轮独立审核 → 质量门槛 → 不可变 Release。每个写操作记录 actor、时间、理由和前后值；历史证据不物理删除。

## 去重

七项特征均已计算或有明确输入：企业、日期、轮次、金额、投资机构 Jaccard、文本相似、引用链。不同明确轮次为强冲突；任何候选仅进入人工审核，不自动物理合并。

## Release

V2 新增 `release_status_history`。创建 Release 时追加 published 历史；撤回/替代只追加状态和 audit log，不修改 `releases` 或 `release_events`。不可变触发器保持不变。
