# 证据等级与发布门槛

- S：法定披露、交易所/监管文件、政府正式文件。
- A：融资企业或投资机构官方公告；不是独立验证。
- B：政府产业平台、高校成果转化平台或信息具体的高可信专业媒体。
- C：行业媒体、采访或可回溯转载。
- D：聚合、自媒体或无法回溯来源，只作线索。

媒体转述不升级为 A。企业、融资事实、日期、轮次、金额、投资机构、资金用途分别绑定证据。整体等级不能简单取最高值；V1 保存编辑确认的整体等级，同时发布质量门槛逐字段检查。

进入 release 必须：企业主体人工确认；融资事实确认；日期或日期范围确认；至少 B 级整体证据；不存在未解决高风险重复；`company_id`、`financing_fact`、`announcement_date` 均有 verified 字段证据。仅 D 级来源会被拒绝。
