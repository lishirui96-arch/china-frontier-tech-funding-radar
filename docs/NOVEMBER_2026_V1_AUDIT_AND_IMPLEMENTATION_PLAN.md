# 2026年11月科技产业早期融资与并购样本库 V1.0：项目审计与实施计划

审计日期：2026-11-25（Asia/Singapore）  
数据截止：2026-11-25；11月尚未结束，所有覆盖统计必须标记为月内增量样本。

## 1. 审计结论

当前项目可以作为样本库基础继续扩展，不应另建数据库或重写审核体系。现有 SQLite Schema V2 已覆盖来源、原始文档、企业、投资机构、融资事件、字段级证据、重复候选、人工去重决定、两轮审核、审计日志、发布批次和不可变发布快照。内部审核站使用 Streamlit，公开站只读取已发布快照，二者边界清晰。

数据库当前没有 `funding_events`、`companies`、`investors`、`raw_documents` 或发布记录；只有 8 个来源、金额规则和去重规则基础数据。上一轮形成的 25 条11月候选仍保存在 CSV/Markdown 中，尚未进入数据库，符合“人工检查后再导入”的原定边界。

自动测试结果为 58 passed、1 个第三方弃用警告；现有 8510/8511 功能不需要重构。

## 3. 数据缺口

1. `funding_events` 只建模融资，缺少独立并购交易实体、收购方/标的方、交易状态和交易类型。
2. 企业表缺少主营业务、核心产品、核心技术、应用场景、产业链位置和技术问题。
3. 缺少六大一级产业分类、二级赛道和跨领域标签。
4. 缺少标准化技术关键词、原始同义词、企业/事件/来源关联。
5. 缺少候选主题、主题成员、人工命名、合并/拆分/移动及不可覆盖的人审结果。
6. 现有事件缺少“交易日期”和人民币标准化金额字段；汇率未知时必须留空，不能推算。
7. 缺少可从明细重算的月度统计和七工作表 Excel。

## 4. 上一轮25条候选的适用性

上一轮候选包含 A+/B/B+、天使/Pre-A/A 系列，也包含轮次未披露、D轮和战略融资。本阶段不能整批无差别导入：

- D轮明确排除早期融资样本。
- 轮次未披露的事件只保留为来源线索，除非补证后能确认纳入范围。
- 战略融资仅在正文明确存在股权融资交易时纳入，并标记交易性质。
- A++、Pre-B 等原始轮次保留；标准化轮次需采用公开规则并接受人工复核。
- 25条均缺企业/投资机构官方原始披露，证据等级不能高于A级；多数应为A/B级且保持“部分核实”。

## 5. V3数据模型计划

- 新建并购事件、并购参与方与并购-来源关联表。
- 新建企业技术画像及其证据表。
- 新建产业分类、企业标签、技术关键词、关键词同义词和关键词关联表。
- 新建候选主题、主题成员、主题关键词和主题人工动作历史表。
- 所有人工动作写 `audit_logs`；人工最终名称单独保存且自动任务不得覆盖。

迁移只增加表/列，不删除或覆盖现有数据。迁移前后均执行外键检查、完整性检查和测试。

## 7. 验收门槛

- 每个正式样本至少有一个可追溯来源；不可访问来源只能作为待核实线索。
- 未披露金额保持“未披露”，所有金额汇总排除未披露记录并显示披露率。
- 同一企业、同一轮次、同一披露日期的多篇报道只形成一个事件，但来源全部保留。
- 企业技术字段必须绑定来源；没有证据的技术不写入。
- 主题人工最终名称、合并/拆分/移动决定有历史记录，自动任务不可覆盖。
- 公开站不读取未审核样本；本阶段不发布 Release。
- Excel、网站统计和数据库查询结果一致。
