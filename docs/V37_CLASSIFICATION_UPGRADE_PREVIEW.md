- 一级领域：保持10个，全部复用V3.2 ID。

- 需要建立V3.7映射的历史候选事件：55个；其余20个继续待判断或观察。

## 超导与聚变边界

“超导材料与强场磁体”的父级固定为现有“高性能功能材料”(`edc8b06e-95f5-5d50-bc86-eaa6c90b8398`)，不挂在“可控核聚变工程”下。企业只有在主营超导带材、材料或磁体时归入该主题；聚变企业使用超导磁体只构成交叉关联，不改变其主分类。
